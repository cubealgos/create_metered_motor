# `DEC-002` — create_metered_motor, mod id metered_motor, display Create Fly: Metered Motor

**Status:** decided by Kevin, 2026-09-19.

Follows the Create add-on convention `create_brass_compass` set: the folder is the project name,
the mod id drops the `create_` prefix, and the display name states the base mod it belongs to.
Diverges from `standards/marketing/naming-theme.md` (descriptive English, no theme name), the same
divergence the compass recorded and for the same reason — a Create add-on is found by what it
does, not by a theme name.

No domain registered, no six-TLD availability check run: there is no standalone web presence at
1.0. Revisit trigger: a website for the mod, as for the compass.
